# Service Images

Place your service cover images in this directory with the following filenames:

Supported formats: .webp, .jfif, .jpg, .jpeg, .png

Required filenames (match these exactly):
- ppf.webp (or ppf.jfif) - Paint Protection Film (PPF)
- tinting.webp (or tinting.jfif) - Window Tinting
- ceramic.webp (or ceramic.jfif) - Ceramic Coating
- polishing.webp (or polishing.jfif) - Paint Polishing & Correction
- interior.webp (or interior.jfif) - Interior Detailing

The website will automatically try .webp first, then .jfif, then .jpg, then .png if the file isn't found.
